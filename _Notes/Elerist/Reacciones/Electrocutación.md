La electrocutación se logra cuando se combinan los elementos de [[Agua]] y [[Rayo]].

Cuando el objetivo es electrocutado, se realentiza durante un breve periodo de tiempo y recibe un poco de daño constante. El tiempo de electrocutación se incrementa si el objetivo recibe ataques del elemento [[Agua]], y el daño y realentización aumenta si el objetivo recibe ataques del elemento [[Rayo]].
