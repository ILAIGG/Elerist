La sepultura se logra cuando se combinan los elementos de [[Tierra]] y [[Planta]].

El objetivo se queda completamente inmóvil dentro de una "tumba". Esta tumba tiene una cierta cantidad de vida, la cual va perdiendo poco a poco con el tiempo o el jugador la ataca. Si el objetivo recibe ataques de elemento [[Tierra]] o [[Planta]], la "tumba" se repara.
